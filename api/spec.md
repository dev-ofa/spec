## api

### 状态
Draft

### 统一响应 Wrapper

#### 必须字段
- code：整数
- message：字符串
- request_id：字符串

#### 可选字段
- data：对象或数组

#### 语义约定
- code=0 表示成功
- code!=0 表示业务失败或系统错误
- request_id 必须贯穿一次请求与其所有下游调用
- 空数组必须返回 []，不得返回 null 或省略字段

### 错误码分段
- code < 20000：非预期或需要告警的错误
- code >= 20000：预期内或不需要告警的错误

#### 推荐保留码段
- 10000：内部错误
- 10001：资源不存在
- 10002：资源冲突
- 20000：参数校验失败
- 20001：可直接展示给用户的业务提示

### 协议关系
- 应用层响应必须返回 Wrapper
- 传输层失败可直接返回协议错误码与错误体
