# guides
本目录提供各语言/框架的工程化落地指南（implementation guides）。

- 本目录内容是“实现指引”，不是规范（specification）
- 所有实现仍 **必须** 以 [spec](../README.md) 为唯一规范来源与权威来源
- 本目录建议用“推荐/约定”表述；如使用 **必须** 表述，含义是“工程可维护性所需的团队约束”，不改变 spec 的兼容性定义
